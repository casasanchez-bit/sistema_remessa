Como usar o sistema — passo a passo

Guia rápido para o dia a dia. Siga a ordem abaixo na primeira vez que for usar.

1. Cadastros (fazer uma vez para cada item novo)

Prestador de Serviço (terceirizado): menu Cadastros → Prestadores de Serviço. Informe o nome e, se quiser, o telefone. O código é gerado automaticamente.

Produto: menu Cadastros → Produtos. Informe o código do produto (o mesmo já usado na empresa) e a descrição.

Cor/Estampa: menu Cadastros → Cores/Estampas. Informe a descrição da cor ou estampa. O código é gerado automaticamente.

Serviço: menu Cadastros → Serviços. Escolha o Produto, informe a descrição do serviço e o preço (não pode ser zero). Cadastre o serviço depois de já ter cadastrado o Produto correspondente.

2. Lançar uma Remessa (enviar produção para o terceirizado)

  1. Acesse o menu Remessas.
  2. Escolha o Terceirizado e a Data de envio.
  3. Em cada item, escolha o Produto, a Cor/Estampa, o Serviço e a Quantidade enviada.
  4. Clique em + Adicionar item se for enviar mais de um produto/cor na mesma remessa.
  5. Clique em Registrar remessa. O sistema gera um número sequencial automático.
  6. Use o botão IMPRIMIR para gerar o documento em papel (2 vias) para acompanhar a entrega.

3. Lançar um Retorno (quando a produção volta)

  1. Acesse o menu Retornos.
  2. Escolha o Prestador de Serviço — só aparecem na lista os que têm remessas pendentes.
  3. Escolha a Data do Retorno.
  4. Para cada item entregue, escolha a remessa de referência (pode digitar para buscar por nome ou código do produto) e a quantidade retornada.
  5. O sistema não deixa lançar uma quantidade maior do que o saldo pendente daquele item.
  6. Clique em Registrar retorno. Quando a quantidade retornada completa o total enviado, o item fica marcado como Concluída; senão, fica Parcial.

4. Dashboard — saldo pendente

Mostra, por terceirizado, quanto foi enviado, quanto já voltou e quanto ainda está pendente. Use para saber quem ainda precisa devolver produção.

5. Fechamento Mensal — pagamento

  1. Acesse o menu Fechamento Mensal.
  2. Escolha o mês de referência e, se quiser, filtre por um terceirizado específico.
  3. O sistema calcula o valor a pagar com base nas quantidades retornadas no período × preço do serviço.
  4. Use Imprimir para o relatório do período selecionado, ou Resumo por Terceirizado para gerar uma página separada para cada um (útil para entregar individualmente).

6. Backup — proteger os dados

Acesse o menu Backups e clique em Fazer Backup Agora de tempos em tempos (por exemplo, ao final de cada mês, ou antes de excluir algo importante). Os backups ficam guardados ali mesmo e podem ser baixados quando precisar.
