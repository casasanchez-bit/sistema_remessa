Módulo 1 — O que é um Banco de Dados?

💡 Resumo em uma frase: Um banco de dados é um conjunto de "planilhas" interligadas que guardam as informações do seu sistema de forma organizada.

A analogia das planilhas

Pense que você tem várias planilhas no Excel, cada uma com um assunto. No banco de dados do Casa Sanchez é exatamente isso:

Como você conheceNome no banco de dadosO que guarda
Lista de terceirizadosterceirizadosAna Paula, Cintia, Daiana...
Lista de produtosprodutosAlmofada Albania, Almofada Cheia...
Remessas enviadasremessasCabeçalho de cada remessa
Itens das remessasitens_remessaCada produto/cor dentro de uma remessa
Retornos recebidosretornosCada talão de retorno

O que é um ID?

Todo registro no banco tem um número único chamado ID. É como o CPF — não se repete.

Tabela: terceirizados ┌────┬─────────┬──────────────────────────────┐ │ id │ codigo │ nome │ ├────┼─────────┼──────────────────────────────┤ │ 1 │ T-0001 │ CINTIA MONIQUE RODRIGUES │ │ 6 │ T-0006 │ ANA PAULA LEITE MARQUES │ │ 9 │ T-0009 │ HUGO HENRIQUE FERREIRA │ └────┴─────────┴──────────────────────────────┘
🔑 Por que usar ID?
Quando o sistema cria uma remessa para a Ana Paula, ele não grava o nome "ANA PAULA LEITE MARQUES" — ele grava só o número 6. Isso evita erros de digitação e economiza espaço. O banco busca o nome quando precisar.

Módulo 2 — A Linguagem SQL

💡 SQL (fala-se "ésse-quê-éle") é a linguagem que usamos para conversar com o banco de dados. Você faz perguntas, o banco responde com dados.

As palavras principais

Palavra em SQLTraduçãoPara que serve
SELECT"Me mostre..."Escolhe quais colunas exibir
FROM"...da tabela..."Diz de onde buscar os dados
WHERE"...onde/quando..."Filtra os resultados
ORDER BY"...ordenado por..."Define a ordem de exibição

Sua primeira consulta

Pergunta: "Me mostre todos os terceirizados"

SELECT * FROM terceirizados

O * significa "todas as colunas". Poderia escrever SELECT nome, codigo para ver só esses dois campos.

Filtrando com WHERE

Pergunta: "Me mostre só a Ana Paula"

SELECT * FROM terceirizados WHERE nome = 'ANA PAULA LEITE MARQUES'

Pergunta: "Mostre terceirizados cujo nome contém ANA"

SELECT * FROM terceirizados WHERE nome LIKE '%ANA%'
🔍 O símbolo % funciona como "qualquer coisa":
'ANA%' → começa com ANA
'%ANA' → termina com ANA
'%ANA%' → contém ANA em qualquer posição

Ordenando resultados

-- Remessas mais recentes primeiro SELECT numero, data_envio FROM remessas ORDER BY data_envio DESC

DESC = do maior para o menor (decrescente). ASC = do menor para o maior (padrão).

Módulo 3 — Conectando Tabelas (JOIN)

💡 JOIN é a parte mais poderosa do SQL. Ele liga duas tabelas pela chave em comum — como uma ponte entre planilhas.

O problema que o JOIN resolve

A tabela remessas guarda só o número 6 (ID da Ana Paula), não o nome dela. O JOIN vai buscar o nome na tabela terceirizados automaticamente.

remessas terceirizados ┌────┬────────┬────────────────┐ ┌────┬──────────────────────┐ │ id │ numero │ terceirizado_id│ │ id │ nome │ ├────┼────────┼────────────────┤ ├────┼──────────────────────┤ │ 1 │ 1 │ 6 ─────┼──┼──▶ │ ANA PAULA LEITE │ │ 2 │ 2 │ 1 ─────┼──┼──▶ │ CINTIA MONIQUE │ └────┴────────┴────────────────┘ └────┴──────────────────────┘ Resultado do JOIN: ┌────────┬──────────────────────┬────────────┐ │ numero │ nome │ data_envio │ ├────────┼──────────────────────┼────────────┤ │ 1 │ ANA PAULA LEITE │ 2026-06-10 │ │ 2 │ CINTIA MONIQUE │ 2026-06-15 │ └────────┴──────────────────────┴────────────┘

Como escrever o JOIN

-- "Me mostre as remessas com o nome do terceirizado" SELECT remessas.numero, remessas.data_envio, terceirizados.nome FROM remessas JOIN terceirizados ON terceirizados.id = remessas.terceirizado_id
🌉 O ON é a ponte:
ON terceirizados.id = remessas.terceirizado_id
Tradução: "ligue o ID da tabela terceirizados com o campo terceirizado_id da tabela remessas"

JOIN com mais de duas tabelas

Você pode encadear vários JOINs. Exemplo real do sistema:

-- Itens de remessa com nome do produto e do terceirizado SELECT remessas.numero, terceirizados.nome, produtos.descricao, itens_remessa.qtd_enviada FROM itens_remessa JOIN remessas ON remessas.id = itens_remessa.remessa_id JOIN terceirizados ON terceirizados.id = remessas.terceirizado_id JOIN produtos ON produtos.id = itens_remessa.produto_id
✅ Módulo 3 concluído!

Módulo 4 — Contando e Somando (Funções)

💡 SQL também faz cálculos para você — sem precisar de calculadora ou Excel!
FunçãoO que fazExemplo de pergunta
COUNT(*)Conta quantos registros existemQuantas remessas foram feitas?
SUM(campo)Soma os valores de uma colunaTotal de peças enviadas?
AVG(campo)Calcula a médiaMédia de peças por remessa?
MAX(campo)Pega o maior valorMaior remessa em quantidade?
MIN(campo)Pega o menor valorMenor remessa em quantidade?

Exemplo: contar remessas por terceirizado

SELECT terceirizados.nome, COUNT(*) AS total_remessas FROM remessas JOIN terceirizados ON terceirizados.id = remessas.terceirizado_id GROUP BY terceirizados.nome ORDER BY total_remessas DESC
📦 GROUP BY agrupa os resultados.
Sem ele, o COUNT contaria tudo junto e daria um só número. Com ele, você obtém o total separado por terceirizado.

Exemplo: total de peças enviadas vs retornadas

SELECT terceirizados.nome, SUM(itens_remessa.qtd_enviada) AS enviado, SUM(itens_remessa.qtd_retornada) AS retornado, SUM(itens_remessa.qtd_enviada - itens_remessa.qtd_retornada) AS pendente FROM itens_remessa JOIN remessas ON remessas.id = itens_remessa.remessa_id JOIN terceirizados ON terceirizados.id = remessas.terceirizado_id GROUP BY terceirizados.nome

Essa consulta é exatamente o que o Dashboard do sistema executa nos bastidores!

Módulo 5 — Exercícios Práticos

Tente montar a consulta antes de ver a resposta. Não tem certo ou errado — é para treinar o raciocínio!

Exercício 1 ⭐ Fácil

Pergunta: "Quantos produtos estão cadastrados no sistema?"

Dica: você precisa de SELECT, COUNT(*) e FROM.

SELECT COUNT(*) AS total_produtos FROM produtos

✅ O banco vai responder com um único número — a quantidade de produtos cadastrados.

Exercício 2 ⭐ Fácil

Pergunta: "Quais remessas foram enviadas em julho de 2026?"

Dica: use WHERE data_envio LIKE '2026-07%'

SELECT numero, data_envio FROM remessas WHERE data_envio LIKE '2026-07%' ORDER BY data_envio

Exercício 3 ⭐⭐ Médio

Pergunta: "Quantas peças foram enviadas no total para cada terceirizado?"

Dica: você vai precisar de JOIN, SUM e GROUP BY.

SELECT terceirizados.nome, SUM(itens_remessa.qtd_enviada) AS total_pecas FROM itens_remessa JOIN remessas ON remessas.id = itens_remessa.remessa_id JOIN terceirizados ON terceirizados.id = remessas.terceirizado_id GROUP BY terceirizados.nome ORDER BY total_pecas DESC

Exercício 4 ⭐⭐⭐ Difícil

Pergunta: "Qual produto foi mais enviado em quantidade total?"

Dica: JOIN entre itens_remessa e produtos, depois SUM + GROUP BY + ORDER BY + LIMIT 1.

SELECT produtos.descricao, SUM(itens_remessa.qtd_enviada) AS total FROM itens_remessa JOIN produtos ON produtos.id = itens_remessa.produto_id GROUP BY produtos.descricao ORDER BY total DESC LIMIT 1

LIMIT 1 = "me mostra só o primeiro resultado" — ou seja, o campeão de quantidade.
